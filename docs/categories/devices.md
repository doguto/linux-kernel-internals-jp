# デバイスとドライバ {#devices-drivers}

カーネルがハードウェアを検出し、それにドライバをバインドし、主要なデバイスクラスを公開する仕組み — バス、周辺機器、そしてそれらをユーザー空間から統一的に見せるフレームワーク。

- [ドライバ（drivers/）](../drivers/README.md) — デバイスモデルと、ドライバがハードウェアにバインドする仕組み（バス、PCI、デバイスツリー、platform、I2C/SPI）
- [USB（usb/）](../usb/README.md) — ホストがスケジューリングするホットプラグ対応の周辺機器バス: ディスクリプタ、エンドポイント、URB
- [GPU / DRM（drm/）](../drm/README.md) — グラフィックスとディスプレイのスタック: KMSによるモード設定、GEMバッファ、コマンド投入
- [オーディオ / ALSA（alsa/）](../alsa/README.md) — サウンドサブシステム: card/PCM/controlのオブジェクトモデル、リングバッファによるデータパス、組み込みオーディオ向けのASoC
- [入力 / HID（input/）](../input/README.md) — 入力コア、evdev、そして自己記述的なHIDレポートディスクリプタプロトコル
- [TTY / シリアル（tty/）](../tty/README.md) — テレタイプライタに由来する端末モデル: ラインディシプリン、シリアルコア/UARTドライバ、疑似端末
